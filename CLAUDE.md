# VV AUTOGROUP — карта проекта

Компания подбирает автомобили из России, Европы, Кореи и Китая.
Контент публикуется в Telegram и Instagram.

## Критические правила

- Перед предложением новых тем публикаций — сверяться с
  `docs/content-topics.md`. Темы из раздела «уже публиковали» не
  предлагать повторно как свежие.
- Позиционирование и тон контента — см. `docs/content-topics.md`
  (раздел «Позиционирование»).
- В каждом посте (Telegram/Instagram) в блоке контактов всегда
  указывать: 📱 Пишите: @Vovhik_800 · ☎️ Звоните: +7 900 699 1444 —
  Владимир.
- У VV AUTOGROUP есть собственный сервис для обслуживания и ремонта
  купленных автомобилей (ТО, ремонт, запчасти под комплектацию).
  Это ключевое конкурентное преимущество — акцентировать в постах
  про постпродажное обслуживание, а не подавать это как «проверяем
  чужие сервисы».
- Действует контент-план на 30 дней (26.08–23.09.2026), см.
  `docs/content-plan-30d.md`. Публикации — по Пн/Ср/Пт в 09:00.
  Автоматических
  напоминаний нет (технически недоступны для этого проекта): в день
  публикации пользователь сам пишет в чат что-то вроде «тема на
  сегодня» — по этому сигналу сразу взять тему по сегодняшней дате из
  `docs/content-plan-30d.md`, подготовить черновики поста для Telegram
  и описания карусели для Instagram по этой теме и прислать на
  согласование. Темы из плана не предлагать повторно как «новые».
